# skill の扱い

このリポジトリが動作に必要とする手順は、すべてリポジトリ内に持つ。グローバルの skill には依存しない。

## 同梱するもの

| 名前       | 場所   | 用途                                   |
| ---------- | ------ | -------------------------------------- |
| `SETUP.md` | ルート | 初期設定の手順。設定完了後に削除される |

`SETUP.md` は skill として自動検出されない。`AGENTS.md` が明示的に指す。

## 任意で併用してよいもの

次はグローバルの skill であり、配布先に存在するとは限らない。存在する場合だけ併用してよい。
存在しない場合は、同梱の手順だけで進める。

| 名前       | 用途                                                     | 存在しない場合の代替                                  |
| ---------- | -------------------------------------------------------- | ----------------------------------------------------- |
| `grilling` | 計画や設計を質問で詰める。各質問に推奨回答を添えて進める | 質問を1つずつ、推奨回答を添えて自分で組み立てて進める |

## 生成する skill の配置先

`templates/skill.md` から生成する skill は、4ツールとも `<name>/SKILL.md` の形式で共通する。frontmatter は `name` と `description` だけを使う。配置先は、利用者が使うツールに合わせる。使うツールが不明な場合は、推測せず利用者に確認する。

| ツール      | 配置先                           |
| ----------- | -------------------------------- |
| Kiro        | `.kiro/skills/<name>/SKILL.md`   |
| Claude Code | `.claude/skills/<name>/SKILL.md` |
| Gemini CLI  | `.agents/skills/<name>/SKILL.md` |
| Codex CLI   | `.agents/skills/<name>/SKILL.md` |

Gemini CLI は `.gemini/skills/` も読むが、Codex CLI と共通にするため `.agents/skills/` を使う。複数のツールを併用する場合は、使うツールごとの配置先に生成し、すべてのパスを `PROJECT.md` の「Canonical locations」に記録する。

## 規則

- 任意の skill を、必須の手順の前提にしない。
- 外部の skill の本文を、このリポジトリへ複製しない。複製すると、元の更新に追従できない。
- 参照は、リポジトリ内の明示パスで書く。`~/.kiro/skills/` を探索する指示を書かない。
- 新しい skill を同梱する場合は、この表に名前、場所、用途を追記する。
