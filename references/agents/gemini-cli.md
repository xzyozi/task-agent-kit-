# Gemini CLI の agent 定義

共通の本文構造は `references/agent-anatomy.md` に従う。この文書は、Gemini CLI 固有の配置先、キー、権限だけを書く。

## 配置先と形式

| 配置先                     | 形式                   | 本文の置き場所         |
| -------------------------- | ---------------------- | ---------------------- |
| `.gemini/agents/<name>.md` | Markdown + frontmatter | frontmatter の後の本文 |

## 名前の制約

`name` には、小文字・数字・ハイフン・アンダースコアのみ使える。

## 使うキーと権限の制御場所

使うキーは、この表にあるものだけにする。表にないキーは、公式の仕様で実在を確認できるまで使わない。

| 使うキー                           | 権限の制御場所                                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `tools`、`mcpServers`、`max_turns` | Policy Engine（`~/.gemini/policies/*.toml`）。agent 定義側に approval に相当するキーは確認できていない |
