# Codex CLI の agent 定義

共通の本文構造は `references/agent-anatomy.md` に従う。この文書は、Codex CLI 固有の配置先、キー、権限だけを書く。

## 配置先と形式

| 配置先                      | 形式                     | 本文の置き場所                |
| --------------------------- | ------------------------ | ----------------------------- |
| `.codex/agents/<name>.toml` | TOML（1ファイル1 agent） | `developer_instructions` の値 |

`templates/agent.md` は Markdown のままにする。Codex を選んだ場合だけ、雛形の本文を `developer_instructions` に入れた `.toml` に変換して出力する。

`developer_instructions` には、TOML の複数行リテラル文字列（`'''` で囲む。エスケープ不要）を使う。本文に `'''` が含まれる場合だけ、複数行基本文字列（`"""`）に切り替え、`\` と `"` をエスケープする。出力後は TOML として構文が正しいことを確認する。

## 使うキーと権限の制御場所

使うキーは、この表にあるものだけにする。表にないキーは、公式の仕様で実在を確認できるまで使わない。

| 使うキー                                      | 権限の制御場所                                                                                                    |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `model`、`features.* = false`（機能の無効化） | sandbox と approval は親セッションから継承し、agent ファイルでは上書きできない。コマンド許可は `rules` で制御する |
