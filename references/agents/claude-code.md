# Claude Code の agent 定義

共通の本文構造は `references/agent-anatomy.md` に従う。この文書は、Claude Code 固有の配置先、キー、権限だけを書く。

## 配置先と形式

| 配置先                     | 形式                   | 本文の置き場所         |
| -------------------------- | ---------------------- | ---------------------- |
| `.claude/agents/<name>.md` | Markdown + frontmatter | frontmatter の後の本文 |

## 使うキーと権限の制御場所

使うキーは、この表にあるものだけにする。表にないキーは、公式の仕様で実在を確認できるまで使わない。

| 使うキー                                     | 権限の制御場所                                                                                |
| -------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `tools`、`disallowedTools`、`permissionMode` | コマンド単位の allow / ask / deny は `.claude/settings.json` に書く。agent 定義側では書けない |
