# maintenance

テンプレートリポジトリ自体を保守する人のための文書とスキルを置く。
テンプレートを使うプロジェクトの通常の作業では、読まない・変更しない。

## 構成

| パス                           | 役割                                                              |
| ------------------------------ | ----------------------------------------------------------------- |
| `MAINTENANCE.md`               | 保守時の確認項目と、動作確認の進め方                              |
| `skills/template-trial-clone/` | 試用コピー（一時ディレクトリへの clone）を作る skill とスクリプト |

## 配布先での扱い

テンプレートを使うプロジェクトには、このディレクトリは不要である。
初期設定の完了時（`SETUP.md` の手順 5）に、削除するかどうかをユーザーに確認する。

## skill の使い方

この skill は、Kiro などが自動では検出しない場所にある。次のどちらかで使う。

- `AGENTS.md` の指示に従い、`skills/template-trial-clone/SKILL.md` を明示的に読ませる。
- 自動検出させたい場合は、`skills/template-trial-clone/` を、ユーザー全体の skill の配置先（Kiro では `~/.kiro/skills/`）へコピーする。このリポジトリ内の配置先（`.kiro/skills/` など）へコピーすると、配布先に残る。
