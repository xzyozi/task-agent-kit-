# task-agent-kit

特定タスクを消化するための agent 構成（ルール・手順・agent 定義）を、
新しいプロジェクトで素早く立ち上げるための土台。

## 目的

- 「入口 → 安全規約 → タスク手順 → 権限を絞った agent」という流れを、
  プロジェクトごとに再利用できる骨格として提供する。
- 共通の安全規約は記入済みで、タスク固有の部分だけを穴埋めする。
- 実績のある構成（env_builder）の流れだけを参考にし、ドメイン固有の内容は持ち込まない。

## 方針

- 骨格は `skeleton/` に置き、利用側プロジェクトの**ルート**へコピーして使う。
  （`AGENTS.md` や `.kiro/steering/` は、利用側のプロジェクトルートに置かれて初めて読み込まれる。）
- コードのライブラリやプラグイン機構は、2つ目の実例が出るまで作らない。
- 作成するファイルは UTF-8（BOM なし）/ LF とする。
